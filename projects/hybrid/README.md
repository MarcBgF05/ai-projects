# Hybrid Projects

## Objetivo

Agrupar proyectos que combinen agentes con modelos de machine learning, logica analitica, RAG o automatizaciones.

## Que deberia vivir aqui

- agentes que consuman modelos propios,
- flujos con scoring o clasificacion,
- soluciones que mezclen PoC de agentes y componentes de ML,
- experimentos donde la parte estadistica y la parte agentica convivan.
