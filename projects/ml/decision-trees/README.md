# Decision Trees

## Objetivo

Preparar el espacio para experimentos con arboles de decision y modelos relacionados a medida que el portafolio crezca.

## Que deberia vivir aqui

- implementaciones iniciales,
- pruebas de particion y criterios,
- comparaciones con otros modelos clasicos,
- futuros experimentos de ensamblados si decides extenderlo.
