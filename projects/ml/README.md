# ML Foundations

## Objetivo

Mostrar fundamentos solidos de machine learning clasico mediante implementaciones propias, ejercicios y experimentos controlados.

## Como se organiza

- `linear-regression/` para implementaciones y pruebas de regresion lineal.
- `logistic-regression/` para clasificacion binaria y analisis inicial.
- `decision-trees/` para futuros experimentos de arboles y modelos relacionados.
