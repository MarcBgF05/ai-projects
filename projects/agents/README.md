# Agent PoCs

## Objetivo

Reunir las pruebas de concepto de agentes que sirvan para demostrar diseno, orquestacion, herramientas y evolucion tecnica.

## Como se organiza

- `adk/` sera la linea principal de trabajo.
- `langchain/` queda listo para pruebas basadas en cadenas y herramientas.
- `langgraph/` queda listo para flujos mas estructurados con grafos.
