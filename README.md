# AI Engineer Portfolio

Repositorio personal para organizar PoC de agentes, ejercicios de machine learning clasico y proyectos hibridos orientados a construir un perfil solido como AI Engineer Jr.

## Enfoque

- PoC de agentes con ADK como stack principal.
- Proyectos futuros con LangChain y LangGraph.
- Implementaciones propias de regresion lineal, regresion logistica y mas adelante arboles de decision.
- Experimentos que mezclen agentes con modelos y pipelines de ML.

## Objetivo del portafolio

Este espacio esta pensado para mostrar:

- criterio al estructurar proyectos de IA,
- practica real con agentes y herramientas,
- fundamentos tecnicos de ML implementados por cuenta propia,
- capacidad para evolucionar de PoC pequenos a soluciones mas completas.

## Primer proyecto

El primer directorio semilla es `projects/agents/adk/001-starter-agent/`.
Por ahora solo deja el espacio preparado para que agregues luego el codigo, prompts, herramientas y documentacion del primer PoC.

## Siguiente paso sugerido

Cuando quieras expandirlo, puedes usar una convencion simple por proyecto:

- `README.md` para objetivo, arquitectura y resultados.
- `src/` para codigo fuente.
- `tests/` para validacion.
- `assets/` para capturas o diagramas.
